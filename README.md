# Abhro Shome Pias

Personal academic website for Abhro Shome Pias, a Ph.D. student in Industrial and Systems Engineering at Auburn University.

Live site: https://abhro034.github.io/

## Editing the site

- Homepage and CV: `_pages/about.md` and `_pages/cv.md`
- Header links: `_data/navigation.yml`
- Publications: `_publications/`
- Projects: `_portfolio/`
- Teaching: `_teaching/`
- Site settings and profile: `_config.yml`

The site uses the [Academic Pages](https://academicpages.github.io/) Jekyll template. GitHub Actions builds and deploys it to GitHub Pages when `master` changes.

To preview locally, install Ruby and Bundler, run `bundle install`, then `bundle exec jekyll serve`.
